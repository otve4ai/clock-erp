# Сохранённые SMS-шаблоны

Статус: draft (реализовано в рабочей ветке, публикация не подтверждена).

Единственный источник текста — `sms_templates.message_text` в разделе
«SMS → Шаблоны». Предпросмотр (`POST /api/v1/sms/templates/preview`) и отправка
читают актуальный активный шаблон по ID через `SmsStore.render_saved_template`.
Правка карточки применяется к следующим отправкам; выключенный шаблон недоступен.
Для будущего фонового задания применяется тот же метод с серверными данными
заказа. Эта правка не запускает расписание 3/5/7 и не отправляет сообщения.

`{tracking_number}` и `{Накладная}` равнозначны. Значение берётся из снимка
выбранного заказа существующим `get_order_tracking`, а не из браузерного payload.
Если в снимке накладная отсутствует, используется единственная накладная связанных продаж Tictactoy с тем же номером заказа. Повторяющиеся товарные строки объединяются; разные накладные, отсутствие или некорректный номер блокируют предпросмотр и отправку.
`{client_name}` получает `first_name` либо поле `customer` исходного заказа.
ФИО не разбирается эвристически: если источник содержит полное имя, оно сохраняется.
Без имени начальное обращение с запятой убирается.

Текст выбранного шаблона в форме доступен только для чтения. Для произвольного
текста нужно выбрать «Без шаблона». Незаполненные фигурные переменные блокируются
также на уровне сервиса отправки. При смене клиента выбранные связи сбрасываются;
устаревший асинхронный ответ не заменяет свежий предпросмотр.

## Включение существующего шаблона

После публикации кода открыть «СДЭК — ожидает получения», включить «Активен»
и сохранить. Переписывать текст или создавать дубликат не нужно: русская переменная
из уже сохранённой карточки поддерживается. Включение шаблона само по себе
не запускает рассылку. Проверить предпросмотр на заказе с накладной; реальные
тестовые сообщения отправлять только на согласованный пользователем номер.

Проверки: `tests.test_sms` (временные БД, подменённый провайдер). На Windows
Linux `fcntl.flock` подменяется только в тестовом процессе; межпроцессная
Linux-блокировка таким запуском не проверяется.
