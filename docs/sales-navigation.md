# Переход после проведения продажи

Статус: current. Проверено по коду 2026-09-25; не подтверждает выкладку.

После проведения заказа Tictactoy открывается полный список этого канала.
Параметр `highlight_sale` подсвечивает строки созданной продажи в таблице и
мобильных карточках, не ограничивая список и показатели. При первом открытии
выбирается страница с этой продажей. Сообщение об успешном проведении и
существующее уведомление об остатках сохраняются.

Ссылки «Открыть продажу» с `sale_id` показывают только строки этой продажи
(точное совпадение ID). Фильтр `order_number` сохраняет существующий поиск
по номеру. В обоих режимах над таблицей видна плашка с номером заказа и
кнопкой «Показать все», открывающей полный список текущего канала.

Проверки: `test_order_tictactoy_sale.py`, `test_sales_server_filters.py`.
